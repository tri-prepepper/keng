# 🦘 캥거루 러시: 스카이 서밋

구름 위 공중 코스에서 펼쳐지는 3D 멀티플레이 장애물 레이스 게임.

**플레이:** https://tri-prepepper.github.io/keng/

- 방 만들기 → 메뉴의 "열려 있는 방" 목록에 공개 → 다른 사람들이 눌러서 입장 → 방장이 시작
- WASD 이동 · Space 점프 · Shift 다이브 · E 아이템 · 마우스 드래그 시점
- 매 라운드 코스가 랜덤으로 만들어져요
- 대기실에서 내 캥거루 꾸미기 (헬멧 색 · 털 색 · 액세서리)
- 아이템 최대 2개 보유: 부스터 · 슈퍼점프 · 실드 · 발차기 · 캥거루 주머니 · 강타
- 3라운드를 통과하고 정상의 황금 문을 가장 먼저 터뜨리면 우승!
